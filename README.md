# Contact a Samaritan – prototype

A clickable prototype of the redesigned Samaritans "Contact a Samaritan" page, in three versions.

- `index.html` – version 1
- `v2.html` – version 2
- `v3.html` – version 3

Each file is fully self-contained (fonts, images and scripts are embedded), so there's no build step. Use the "Version" dropdown in the yellow bar to switch between them.

## View it online with GitHub Pages

1. Create a new repository on GitHub and upload `index.html`, `v2.html`, `v3.html` and this `README.md` to the root.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then **Save**.
4. After a minute or two the prototype will be live at `https://<your-username>.github.io/<repository-name>/`.

## Notes

- The YouTube video loads from YouTube, so it needs an internet connection.
- The yellow bar at the top switches between versions and between the desktop and mobile views.
- The red button below the chat card switches between the online and offline versions of the card.
- Links marked as placeholders (`#`) are not yet connected.
