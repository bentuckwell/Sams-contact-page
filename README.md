# Contact a Samaritan – page design

A design prototype of the Samaritans "Contact a Samaritan" page.

`index.html` is fully self-contained (fonts, images and scripts are embedded), so it works on its own with no build step.

## View it online with GitHub Pages

1. Create a new repository on GitHub and upload `index.html` and this `README.md` to the root.
2. In the repository, go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to "Deploy from a branch", choose `main` and `/ (root)`, then **Save**.
4. After a minute or two the page will be live at `https://<your-username>.github.io/<repository-name>/`.

## View it locally

Download `index.html` and open it in any modern browser.
